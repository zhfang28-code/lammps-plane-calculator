# LAMMPS 区域、倾斜原子层与应变矩阵计算器

一个无需安装、可直接在浏览器中运行的静态网页计算器。

## 项目文件

- `index.html`：GitHub Pages 入口与全部页面结构
- `assets/css/styles.css`：界面排版、配色和响应式样式
- `assets/js/app.js`：平面、倾斜原子层、位移、六面体与应变矩阵的全部计算逻辑
- `README.md`：功能、使用方法与项目结构说明
- `.gitignore`：排除本地日志、轨迹、编辑器缓存和临时文件

本项目不依赖第三方 JavaScript 库、外部字体或外部图片；示意图由页面中的 SVG 根据输入参数实时绘制。因此，上述文件就是网页运行与维护所需的完整源码。

## 功能

- 根据平面上三个原子的笛卡尔坐标计算单位法向量、平面常数和平面方程
- 生成可直接使用的 LAMMPS `region plane`、原子筛选与导出命令
- 可选择法向正侧（`side in`）或反侧（`side out`），LAMMPS 与 Atomsk 命令同步更新
- 生成对应的 Atomsk 平面切割命令，并将计算说明与可复制命令分开显示
- 根据底面 A、B、C、D 与法向厚度自动生成 E、F、G、H，形成两个严格平行端面的凸六面体
- 自动检查底面四点的共面性、连续顺序和凸性，并通过六个 `region plane` 与 `intersect 6` 选择内部原子
- 生成 Atomsk 六面连续裁剪命令，逐面旋转并删除六面体外部原子
- 由三个原子坐标定义任意倾斜面，并按自选排数与上下层厚度生成有限厚度原子层
- 可选取界面两侧两个相邻原子 P1、P2，以三维中点定位中心倾斜面；A、B、C 仅保留倾斜方向，平面自动沿 Z 平行移动并同步更新全部结果
- 可用一条垂直于倾斜面的平面按 `m·X ≥ K` 或 `m·X < K` 裁剪所有原子层
- 横向裁剪边界点 S 可直接粘贴 XYZ，也可一键采用当前有效倾斜面的 A、B 或 C 点；启用双原子中点定位时会自动使用平移后的对应点
- 参考原子校准组按照当前层数自动生成并固定对应 `upper_1`、`lower_1`、`upper_2`、`lower_2`……；无需手动新增或选择目标层，每层仍可填写不限数量的层内点和层外点
- 每个校准组可独立收起或展开；收起后仍显示目标层、层内/层外点数量及通过、可优化或冲突状态
- 参考原子的层内点与层外点各使用一个不限行数的坐标框；每个非空行自动编号为 `P_in1…` / `P_out1…`，并即时显示识别结果
- 当一组全部参考点可由目标层外边界分开时，以最外侧层内点和最近层外点的法向投影中点计算并应用该目标层厚度；约束冲突时给出原因而不修改参数
- 动态绘制上下层、中心面、裁剪界面与保留方向，并自动列出各层在指定 `(X,Y)` 处的 Z 坐标边界
- 生成各层 `region plane` / `intersect`、上下层 `group union` 及其余原子 `group subtract` 命令
- 面内位移方向可选 A→B、A→C、自定义向量，或直接粘贴两点 P、Q 后由程序计算并投影 P→Q
- 总相对位移既可沿倾斜面的两个正交方向填写，也可按标准坐标系直接填写 `ΔX`、`ΔY`、`ΔZ`；两种方式均按 `Δupper=+Δrel/2`、`Δlower=−Δrel/2` 生成 `displace_atoms` 命令
- 所有固定数量的多点输入均合并为一个多行坐标框：平面 A/B/C(E)、六面体 A–D、倾斜面 A/B/C、中间界面 P1/P2 及位移方向 P/Q 都按行序自动识别并直接计算，无需再点击导入按钮
- 单独的原子点、边界点和自定义方向向量使用单行 XYZ 粘贴框；所有坐标均支持空格、逗号、括号及 `x=… y=… z=…`，只有厚度、距离和标准位移分量等独立标量保留分栏输入
- 多点坐标框会逐行显示“第几行 → 点名 → 实际 XYZ”，并提示空行、无效行、多余数字和超出所需数量的行；识别区采用紧凑、可滚动样式
- 主要参数直接展示，LAMMPS 命名、精度和文件选项集中在可折叠的高级设置中
- 所有 LAMMPS 与 Atomsk 命令输出均可展开或收起，复制按钮只复制命令正文
- 平面、六面体、原子层范围与位移计算说明默认收起，需要时可单独展开
- 三个计算器大分类固定在页面左侧；每个大板块内部的步骤按钮横向悬浮在内容顶部
- 输入区与实时结果区左右并排；长表单滚动时右侧结果保持可见并可独立滚动，减少输入与预览之间的来回查找
- 平面、六面体、倾斜层、中点定位和位移等结果统一显示为紧凑的浅蓝逐行清单，以 `01 · 名称 → 结果` 的方式减少大块空白
- 各编号输入步骤均可独立收起或展开；默认只展开每个板块的第一步，从顶部步骤按钮跳转时会自动展开目标步骤
- 内部点 Q、双原子中点、参考原子校准和横向侧边界的启用开关统一放在对应步骤标题右侧，并位于收起/展开按钮之前
- 页面顶部提供可复制的 MPI 启动命令模板：`mpiexec -np 12 lmp -in`
- 第四大板块可直接填写全局 `εxx、εyy、εzz、γxy、γxz、γyz`，或由初始法向长度、切向相对位移和法向长度变化自动换算工程应变
- 可由倾斜面 A、B、C 建立局部正交基 `t=A→B`、`n∥A→B×A→C`、`q=n×t`，并将局部应变张量投影到全局 XYZ；非轴对齐有限应变会明确标注为小应变等效投影
- 以一个参考应变率或总加载时间统一全部分量的结束时刻，自动计算每个 `fix deform` 分量的比例、应变率、加载步数与实时应变变量
- 自动生成正交盒转三斜盒、`x/y/z/xy/xz/yz` 联合变形、`stress/atom` 六分量求和、当前/初始代表体积及 GPa 换算命令
- 应力输出使用正确顺序 `xx, yy, zz, xy, xz, yz`，同时生成全局六分量和倾斜面局部 `tn` 剪切、`nn` 法向投影；可选压缩为正或拉伸为正
- 根据 `units`、`atom_style`、`boundary`、数据文件、原子组、代表体积和势函数命令生成 IN 文件骨架；缺失的材料势函数保留 TODO，不自动伪造参数

## 使用方法

打开仓库中的 [`index.html`](./index.html)，或者直接访问 [GitHub Pages 在线版](https://zhfang28-code.github.io/lammps-plane-calculator/)。

录入单个原子或方向时，直接把 `X Y Z` 三个数一起粘贴到对应框内即可，例如 `14.0199 261.154 125.018`、`(14.0199, 261.154, 125.018)` 或 `x=14.0199 y=261.154 z=125.018`。录入多个点时，在同一个框中每行粘贴一个 XYZ；程序按界面标明的行序自动对应 A/B/C、P1/P2 等点名。输入框下方的绿色文字就是程序实际采用的坐标；若数量不足、格式无效、多出数字或多出整行，会立即提示。

六面体只需输入底面 A→B→C→D 与厚度。四点必须共面，并沿凸四边形边界连续排列；程序根据所选法向自动计算 E=A+t·n、F=B+t·n、G=C+t·n、H=D+t·n，再生成 LAMMPS 和 Atomsk 命令。

倾斜原子层默认由 A、B、C 同时确定方向和位置。启用“双原子中点定位”后，程序取 `M=(P1+P2)/2`，保持原法向 `n` 不变，并计算 `ΔZ=n·(M−A)/n_z`，使平移后的中心面通过 M。P1、P2、M 会同步标到截面预览中，层范围、参考原子判定、横向裁剪、LAMMPS 命令和位移投影均使用新平面。若 `n_z≈0`，该平面在固定 X/Y 处没有唯一 Z，因此此定位方式会给出提示并停止计算。

位移板块的“粘贴两点坐标”模式使用 `Q−P` 作为参考方向，并先投影到当前倾斜面再归一化。标准 XYZ 模式则直接把输入的 `(ΔX,ΔY,ΔZ)` 作为 upper 相对于 lower 的总相对位移，不强制投影到倾斜面；页面仍会在平面有效时显示该向量的面内与法向分量，便于检查。

参考原子校准使用有符号法向距离 `s=n·(X−A)` 判断点所在的原子层。`upper_i` 位于中心面的 `+n` 侧，`lower_i` 位于 `−n` 侧，因此二者的距离符号和边界方向不同。程序根据排数自动建立每个目标层的固定校准卡，其中全部 `P_in` 必须被该层选中，全部 `P_out` 必须被该层排除；层内点和层外点分别粘贴到各自的多行框中，数量不限，空行会被忽略。完全空白的目标层不参与校准判断；开始填写后程序还会检查可选横向裁剪界面。点击某层的优化按钮只改写该目标排厚度，但目标层外侧各排的绝对位置会随累计边界移动。

应变矩阵板块中，三个面上点只能确定加载方向，不能单独确定应变大小。要得到可运行的加载段，还需提供六个目标工程应变分量，或提供初始法向长度 `L0`、切向相对位移 `Δt` 与法向长度变化 `ΔL`，此时 `γ=Δt/L0`、`εn=ΔL/L0`。此外还需给出参考应变率或加载时间、时间步长、盒子类型、边界条件、应力统计原子组和代表体积。若希望仅由原子坐标反算完整三维形变梯度，则至少需要变形前后四个不共面的对应点，单个平面的三个共面点不够。

默认 YZ 示例表示随 Z 增大沿 `+Y` 偏移，同时沿 Z 压缩：`γyz=+0.2`、`εzz=−0.2`。参考剪切率为 `0.0001 /ps` 时，统一加载时间为 `2000 ps`，自动得到 `zrate=−0.0001 /ps` 和 `2,000,000` 步（`dt=0.001 ps`）。`yz erate` 按初始 Z 盒长定义；若 Z 盒长同时变化而希望剪切率随当前盒长重标定，可使用 LAMMPS 11Feb2026 及更新版本提供的 `erate/rescale`。

项目早期本地文件名为 `LAMMPS平面与四面体区域计算器.html`。为便于 GitHub Pages 识别网页入口，当前仓库使用 `index.html`；样式和计算逻辑已分别整理到 `assets/css` 与 `assets/js` 中。
