六面体步骤

六面体设置

只需按边界顺序输入底面 A、B、C、D，再给出沿底面法向的厚度；程序会自动生成平行面 E、F、G、H 和六个裁剪面。

1按顺序输入底面四个顶点

底面：A → B → C → D四点必须共面，并沿凸四边形边界连续排列
XYZ A B C D
从 OVITO 批量填写 A、B、C、D

每行一个坐标，前四行按照 A 到 D 的顺序填入。

2设置六面体厚度

自动计算 E=A+t·n、F=B+t·n、G=C+t·n、H=D+t·n，因此 A–D 与 E–H 必然严格平行，A–E、B–F、C–G、D–H 的长度都等于厚度 t。

原子层步骤

倾斜原子层设置

用三个原子确定中心倾斜面，再设置上下层数量、厚度和可选的侧边界。

1输入中心倾斜面

A、B、C 必须是中心面上三个不共线的原子。

XYZ A B C
从 OVITO 批量填写 A、B、C

每行一个坐标，前三行依次填入 A、B、C。

如果预览中的上层和下层与实际模型相反，切换此选项即可。

2设置上下层数量与厚度

排上层厚度下层厚度

第 1 排最靠近中心面，后续各排依次向外累计。留空距离为 0 时各层连续；大于 0 时中心面两侧会保留一段不选择的区域。

3限制原子层的横向范围（可选）

启用后会增加一条橙色侧边界，只保留这条边界某一侧的原子层。

XYZ M
XYZ S

S 的 X、Y 同时用于计算并显示每一层对应的 Z 坐标。

参考轴决定“往哪个方向判断”，橙色界面本身与该参考轴垂直。数学表达式 m·X 与 K 会在右侧结果中自动给出。
