XYZ A B C

C 是平面上的第三个原子，A、B、C 不能共线。

每行一个坐标，支持空格、逗号或括号；依次填入上方三行。

XYZ Q

六面体设置

输入八个顶点，其中 A–D 和 E–H 是两张对应的平行面；程序会检查其余四个侧面是否能共同闭合为凸六面体。

1选择必须平行的两个面

选择 YZ、XZ 或 XY 时，同一张面上的对应坐标允许在几何容差内有轻微偏差，计算时会取平均值以保证两面严格平行。

2按顺序输入八个顶点

平行面 1：A → B → C → D四点沿边界顺序排列
XYZ A B C D
平行面 2：E → F → G → H分别对应 A、B、C、D
XYZ E F G H
连接规则：A–E、B–F、C–G、D–H。由此自动形成四个侧面 A-B-F-E、B-C-G-F、C-D-H-G、D-A-E-H。
从 OVITO 批量填写 A、B、C、D、E、F、G、H

每行一个坐标，前八行按照 A 到 H 的顺序填入。

倾斜原子层设置

用三个原子确定中心倾斜面，再设置上下层数量、厚度和可选的侧边界。

1输入中心倾斜面

A、B、C 必须是中心面上三个不共线的原子。

XYZ A B C
从 OVITO 批量填写 A、B、C

每行一个坐标，前三行依次填入 A、B、C。

如果预览中的上层和下层与实际模型相反，切换此选项即可。

2设置上下层数量与厚度

排上层厚度下层厚度

第 1 排最靠近中心面，后续各排依次向外累计。留空距离为 0 时各层连续；大于 0 时中心面两侧会保留一段不选择的区域。

3限制原子层的横向范围（可选）

启用后会增加一条橙色侧边界，只保留这条边界某一侧的原子层。

XYZ M
XYZ S

S 的 X、Y 同时用于计算并显示每一层对应的 Z 坐标。

参考轴决定“往哪个方向判断”，橙色界面本身与该参考轴垂直。数学表达式 m·X 与 K 会在右侧结果中自动给出。
